# Flipkart Clone - Web App

A simple, mobile-friendly e-commerce web app inspired by Flipkart.

## Features
- Product listing
- Product details
- Add to cart
- Cart management
- Place order (demo)
- Fully responsive (mobile + desktop)

## How to run locally
Just open `index.html` in any browser.

## Live Demo
After deploying to Vercel/Netlify you will get a live link.

## Deploy on Vercel (Free)
1. Go to [vercel.com](https://vercel.com)
2. Import this repository
3. Deploy
